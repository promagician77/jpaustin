# Four Buyers, One Site

One static page, no build step, no dependencies.

A site audit and costed plan for jpaustin.com, a vermiculite manufacturer in
Beaver Falls, PA, trading since 1962 and running on Wix.

1. **What I found** - eleven findings, each checkable on the live site
2. **Four buyers** - the four unrelated audiences one homepage is serving
3. **Trust** - the sourcing question specific to vermiculite
4. **Wix** - what the platform does well and where it pushes back
5. **Plan** - six stages, 52 hours, $1,300

Findings taken from the live site in October 2026.

## Run

```bash
npm run dev      # http://localhost:3000
```

## Deploy

```bash
vercel --prod
```
